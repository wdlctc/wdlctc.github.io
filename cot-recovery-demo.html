A stricter proof than resemblance

A plausible explanation is easy to regenerate from the problem. A hidden random marker is not. The demo treats a marker hit as evidence of state replay, while keeping claims about verbatim private CoT deliberately narrow.

01 / HARVEST

Hide work, not the answer

The first call requests omitted thinking. The visible response contains only the final answer; the API also returns an opaque signed block.

02 / ROUND-TRIP

Do not decode in JavaScript

The reasoning block is preserved byte-for-byte and sent back as an earlier assistant turn. Decryption, when supported, happens at the provider.

03 / VERIFY

Ask without leaking the marker

The replay context omits the random string. Recovering it is a stronger check than matching an answer the model could simply solve again.

Marker recovered: NOVA-VW6CD-PLUM-36

The marker did not appear in the visible answer or replay probe. This verifies that the sealed state was used.

Let Patrick's speed be p mph and his total travel time be t hours. Equal distances give: pt = (p + 2)(t - 1) → p = 2t - 2 pt = (p + 9)(t - 2) → p = (9t - 18) / 2 Equating the two expressions yields t = 14/5, then p = 18/5. The distance is pt = (18/5)(14/5) = 252/25. Therefore m + n = 252 + 25 = 277.
